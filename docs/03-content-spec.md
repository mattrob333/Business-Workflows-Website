# 03 — Content spec

## The homepage — five acts (the site in one scroll)

A scrollytelling documentary: **one company gets diagnosed while you scroll.** Beacon
Mechanical is the patient. kage-style act markers in the margin.

1. **ACT I · The board state** — hero. Headline (Newsreader): *“Business frameworks were
   never wallpaper. They were programs.”* Below/behind: the BMC assembling itself from
   Beacon's facts (`fw/bmc-assemble`), evidence chips landing. Sub-line: the tagline. CTA
   pair: `Watch it run ↓` / `Join the first wave`.
2. **ACT II · The instruments** — the Framework Graph fades in around the canvas; terrain
   arrows press (Five Forces mini), capabilities queue at VRIO's gates. The graph edges
   light as outputs hand off (`motion/route`). Copy teaches the one principle: *frameworks
   don't pass paragraphs — they pass typed state.*
3. **ACT III · The conductor** — everything dims except the flow pipe; the bottleneck backs
   up; **the page's first amber appears here** and nowhere earlier. *“A hundred true
   findings. One binding constraint.”*
4. **ACT IV · The delegation** — the RACI routing animation; a packet stops at a human
   checkpoint; the signature draws. *“Some of the work goes to people. Some to agents.
   Accountability stays human.”*
5. **ACT V · The bridge** — the loop diagram (observe→model→diagnose→prioritize→delegate→
   measure→↺), then: *“You just watched it run once. **Instinct keeps it running.**”*
   Waitlist. Quiet footer.

## The framework page pattern (six full pages)

Seven sections per the appendix §6, v1-scoped:

1. **Animated explanation** — the framework's motion recipe performs on its example company,
   act-pinned. Teaches, never decorates.
2. **Learn** — MDX lesson: plain-language, when/when-not, common failure (each framework's
   "how it became wallpaper" story — SWOT's sticky notes, scorecard decay…), what good looks
   like. Ends with the mono READS FROM / WRITES TO / BEST NEXT panel (from registry).
3. **Explore an example** — pick one of the bound companies; interact: change an input,
   **predict before reveal** (`PredictionPrompt`), run, compare, inspect evidence.
4. **Run it on my business** — v1: the honest door. A beautiful locked panel: *“Your company
   here. The first wave opens soon.”* → waitlist. No fake forms.
5. **Review** — demonstrated inside section 3 via the honesty chips (statuses, evidence,
   challenge affordance shows the reasoning popover).
6. **Handoff** — “What this unlocked” card + one-click into the next framework page with
   the example company's state carried in the URL (the graph edge, made walkable).
7. **Share** — v1: copy-link + og-image per framework (authored, on-brand). Export formats
   arrive with Phase 2.

Chapter pages (the other eleven): hero question, position-in-graph mini-map, motion-concept
teaser (static frame from §10 table), lesson summary (~400 words), `Notify me when the lab
opens`.

sourced to a pack object — Ruling 4):

## The flagship Strategy Run — *Find What Matters Now* (scripted)

Beacon Mechanical through BMC → Five Forces + VRIO → SWOT/TOWS → ToC → RACI. Twelve steps,
each a `RunStep` with: state-in panel, an interaction (at minimum one per step:
prediction / assumption-slider / lens-compare / event-injection at step 9 — “a competitor
raises capital: which frameworks re-run?”), the authored analysis with honesty chips, and
the handoff. Persistent right rail: the company state accreting (the save file, visibly
growing). Final screen: the constraint in amber, the intervention plan, the RACI routing —
then the bridge: *“Instinct keeps it running.”* A `SIMULATION` mono chip is pinned in the
header for the entire run (Ruling 4).

## Voice

The essays' voice: confident, concrete, no hype-words ("revolutionary," "unleash" are
banned), short sentences land the punches, numbers always sourced. Lessons written to be
quotable — every framework page contains one pull-quote-worthy line, set in Newsreader
italic. The reader is a smart operator, never talked down to.
