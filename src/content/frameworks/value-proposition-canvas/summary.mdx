## What it is

The Value Proposition Canvas puts two halves face to face and asks whether they actually
meet. On one side, the customer profile: the jobs, the pains that get in the way, the gains
that would count as a good outcome. On the other, the value map: the products, the pain
relievers, the gain creators the business has built.

Then it draws lines. A pain reliever that lands on a real pain is a match. A feature that
lands on nothing is not a failure of marketing — it is a feature nothing hires. A pain with
nothing pointing at it is the most valuable output the framework produces, because it is a
gap that already exists in the market and already exists in your customers' week.

Fit is the count of connections that survive that test, and it earns a number only when the
jobs half came from evidence rather than from a workshop.

## When it earns its place

Run it directly after the jobs work, using its output as the profile side. Run it before any
prioritisation framework, because deciding what to build next is only meaningful once you
know what the current build already covers.

Run it separately per segment. One canvas across all customers averages two different
businesses into a shape that describes neither, and the averaging is invisible in the result.

> The unmatched row is the finding. Everything else on the canvas is a description of what
> you already shipped.

The failure mode is drawing the value map first and reverse-engineering the profile to
justify it. The canvas is symmetric, so it cannot stop you, and the result looks exactly like
a good fit — every reliever attached to a pain that was written to receive it. The tell is
that no feature came out unmatched. Real products always have some.

What good looks like: the profile side sourced to interviews and dated, the map side listing
what actually exists rather than what is planned, unmatched items on both sides left visibly
unmatched, and a fit score that moves when either side changes. The output is a fit
assessment plus a set of open questions — the honest kind of output, which names what is
still unknown rather than rounding it away.
