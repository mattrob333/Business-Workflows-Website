## What it is

Blue Ocean asks which factors an industry competes on, and then asks a harder question about
each of them: eliminate, reduce, raise, or create?

The instrument is the value curve. List the factors buyers in a market are told to compare —
price, feature depth, support hours, brand, speed of setup — and plot where the typical
competitor sits on each. The result is a shape, and the shape is usually shared by every
company in the category, which is the actual finding. Everyone is competing along the same
line, so the only remaining lever is doing slightly more of it for slightly less money.

A new curve is a different shape, not a better score. Raising three factors while eliminating
two is a strategy; raising all of them is a budget request.

## When it earns its place

Run it when differentiation has quietly stopped existing — when win/loss reasons collapse to
price and the roadmap is a list of things competitors already shipped. Run it after the
customer frameworks, because the factors worth eliminating are the ones no job actually
hires, and only the job evidence can tell you which those are.

Do not run it as an ideation game. The four verbs are constraints, not prompts, and the
first two carry all the risk: *eliminate* and *reduce* are the moves that make the curve a
different shape, and they are the moves a workshop will quietly skip.

> If nothing on the list gets eliminated, you have not drawn a new curve. You have drawn the
> old one, taller.

The second failure is drawing the curve you would like to have without pricing it. Every
raised factor costs something to deliver, and the elimination column is where that money is
supposed to come from. A curve where the raises are funded by hope is a pitch, not a
position.

What good looks like: factors drawn from real buying criteria rather than from the product
menu, a proposed curve that is visibly a different shape, an explicit statement of which
customers the eliminations will lose, and the assumptions that would have to hold for the
trade to be worth it. The output feeds straight back into the cross that generates options —
a new value curve is a strength that did not exist last quarter.
